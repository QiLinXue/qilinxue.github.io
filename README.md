# QiLin Xue - Personal Website

A modern personal website showcasing my work as a PhD student in quantum optics, software engineering experience, and teaching accomplishments.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Docker

```bash
# Development with hot reload
docker-compose --profile dev up --build

# Production
docker-compose up --build
```

## Tech Stack

- React 18 + TypeScript
- Tailwind CSS
- Framer Motion
- Docker + Nginx
